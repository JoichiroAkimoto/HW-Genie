# ヒーローショッピング (HW-Genie 版)
## ワークフロー
> **Tip**: 複数のアカウントを使用している場合は、事前に `uv run hw-genie auth --list` で正しいアカウント別名を確認することを推奨します。

1. 実行コマンド:
   ```bash
   uv run hw-genie shop
   ```
   ターゲットショップのヒーローソウル、ソウルショップの全アイテム、タウンショップの固定スロット（2,4,5,6）を購入済みチェックの上で一括購入します（ペットポーションは含まない。`daily` / `full` ルーチンでのみ購入）。タウン購入はゴールドを消費するため残高に注意してください。
