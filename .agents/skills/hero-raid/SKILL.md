# ヒーローレイド Skill (HW-Genie 版)
## ワークフロー
> **Tip**: 複数のアカウントを使用している場合は、事前に `uv run hw-genie auth --list` で正しいアカウント別名を確認することを推奨します。

1. レイド対象のミッション ID を指定して実行します。ID を省略した場合は、デフォルトのミッションリストが自動的に適用されます。
   ※各ミッションはデフォルトで 3 回レイドされます。

2. 実行コマンド:
   - **デフォルトリストで実行する場合**:
     ```bash
     uv run hw-genie raid hero
     ```
   - **特定のミッション ID を指定して実行する場合**:
     ```bash
     uv run hw-genie raid hero 1 5 10
     ```
   - **認証情報を同時に更新する場合**:
     ```bash
     uv run hw-genie raid hero --curl 'PASTE_CURL_COMMAND_HERE'
     ```

## 補足: デフォルトミッションリスト
参考用（コード側で管理されています）:

## オプション
- `--account`, `-a`: アカウント別名を指定して実行します。
- `--times`, `-t`: 各ミッションを何回実行するか（デフォルト 3 回）。通常は指定不要です。
- `--curl`, `-c`: 認証情報を抽出してセッションを最新の状態に更新します。

## 完了後の報告
コマンド実行後、レイドを実行したミッションの結果と、最後に出力された「Final Account Status」の内容（プレイヤー名、レベル、順位、リソース）を総合して、全体的な実行サマリーをユーザーに報告してください。
