# ヒーローレイド Skill (HW-Genie 版)
## ワークフロー
1. レイド対象のミッション ID を指定して実行します。指定がない場合、以下のデフォルトリストを使用します:
   `[1, 5, 10, 11, 16, 20, 25, 26, 31, 35, 40, 41, 46, 50, 55, 57, 61, 65, 70, 72, 76, 80, 85, 86, 91, 95, 100, 101, 106, 110, 115, 116, 121, 125, 130, 131, 136, 140, 146, 151, 155, 161, 166, 170, 177, 181, 185, 193, 198, 203, 204, 205, 209, 214]`
2. 実行コマンド:
   - 通常実行（保存済みのセッションを使用）:
     ```bash
     .venv/bin/hw-genie raid hero 1 5 10 ... 214 --times 3
     ```
   - 認証情報を同時に更新する場合（ブラウザからコピーした curl を使用）:
     ```bash
     .venv/bin/hw-genie raid hero 1 5 10 ... 214 --curl 'PASTE_CURL_COMMAND_HERE' --times 3
     ```

## オプション
- `--times`, `-t`: 各ミッションを何回実行するか（デフォルト 3 回）。
- `--curl`, `-c`: 認証情報を抽出してセッションを最新の状態に更新します。
- `--account`, `-a`: アカウント別名を指定して実行します。

## 完了後の報告
コマンド実行後、レイドを実行したミッションの結果と、最後に出力された「Final Account Status」の内容（プレイヤー名、レベル、順位、リソース）を総合して、全体的な実行サマリーをユーザーに報告してください。
