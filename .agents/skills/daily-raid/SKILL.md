# デイリーレイド (HW-Genie 版)
## ワークフロー
1. （オプション）集めたいアイテムのレイドリクエストをブラウザで `Copy as cURL` します。
2. 実行コマンド:
   - 基本ルーチンのみ:
     ```bash
     uv run hw-genie daily
     ```
   - アイテムレイドをエナジー限界まで実行する場合:
     ```bash
     uv run hw-genie daily --curl 'PASTE_CURL_COMMAND_HERE'
     ```

## 実行される内容
1. **ヒーローレイド**: 設定された主要ミッションを各3回ずつ実行します（スタミナ自動回復は行いません）。
2. **アイテムレイド**: `--curl` が指定されている場合、そのアイテムをスタミナがなくなるまで繰り返し取得します。
3. **ショッピング**: ソウルショップでヒーローのソウルストーン以外の全アイテムを購入し、余ったソウルストーンを換金します。

## 完了後の報告
コマンド実行後、実行された各ステップ（ヒーローレイド、アイテムレイド、ショッピング）の結果と、最後に出力された「Final Account Status」の内容（プレイヤー名、レベル、順位、リソース）を総合して、全体的な実行サマリーをユーザーに報告してください。
